# 生活黑客群島（Life Hack Archipelago）

以城市探索為入口的生活情報平台。第一版可操作原型：**全景探索 → 點選島嶼 → 閱讀資訊 → 返回原位置**。

> 所有情報皆為**示範內容**，未串接真實來源，不是即時新聞。

## 執行
單一靜態檔案，直接開啟 `index.html`，或部署到 GitHub Pages（Settings → Pages → Branch: `main` / root）。
Three.js r128 由 cdnjs 載入；無法使用 WebGL 時自動改為清單模式。

## 資訊架構
- 6 座主題島 = 分類；每島 3 棟建築 = 子主題；中央「今日情報塔」= 今日更新入口。
- 島上浮標 = 24 小時內新增或更新；數量同時以文字（「新 2」）呈現，不只靠顏色。
- 重要程度以「▲ 重要／● 關注／○ 一般」文字＋圖示表達。

| 主題島 | 建築（子主題） |
|---|---|
| 聰明消費島 | 商店（優惠）、市集（比價）、咖啡館（訂閱管理） |
| AI 工具島 | 創意工作室（AI 工具）、小型實驗室（工作流）、教室（實用教學） |
| 居家生活島 | 住宅（收納）、家居店（家電）、花園（空間改善） |
| 職場效率島 | 辦公室（生產力）、共享工作空間（協作技巧）、職涯塔（職涯） |
| 城市探索島 | 車站（交通）、活動廣場（活動）、公園（在地情報） |
| 數位安全島 | 燈塔（防詐）、守望站（帳號安全）、小屋（隱私） |

## 互動
- 桌面：拖曳平移、滾輪縮放、滑過顯示島嶼摘要、點選聚焦並開啟側邊面板；關閉後鏡頭回到原位置。
- 手機：單指平移、雙指縮放；底部抽屜可展開。地圖只在畫布內接收手勢，不與頁面捲動衝突。
- 鍵盤：Tab 選島、方向鍵平移、＋／－縮放、0 回到全景、Esc 關閉面板。
- 搜尋與篩選（關鍵字、主題、更新時間）一律以清單呈現結果；城市模式與清單模式共用同一狀態。
- 新情報以低干擾提示通知，不移動鏡頭、不打斷閱讀。

## 視覺規範
- 色彩：奶油白 `#FBF7EF`、暖米 `#F3ECE0`／`#E7D9C3`、鼠尾草綠 `#7F9F86`、珊瑚橘 `#DD7C5E`、低彩度海水藍 `#A5C3CA`、文字 `#36322C`。
- 字體：標題 LXGW WenKai TC，內文 Noto Sans TC。
- 3D：等角正交相機、霧面材質（roughness 0.9、無金屬）、柔和日照與接觸陰影；六角地塊與木橋。

## 資料結構
`<script type="application/json" id="lh-data">` 與場景程式分離，日後可改由 CMS／API 提供：
```json
{ "islands": [{ "id", "name", "intro", "ground", "accent", "angle", "subs": [{ "id", "name", "topic", "type" }] }],
  "items":   [{ "id", "island", "sub", "imp": "high|mid|low", "title", "summary", "tags", "why", "action",
               "source", "url", "published", "updated" }] }
```
介面區分「內容更新時間」（每則情報）與「系統最後同步時間」（狀態列）。

## 狀態
「關於此原型」中可預覽：載入中、空資料、同步失敗、3D 不支援、新情報提示。
